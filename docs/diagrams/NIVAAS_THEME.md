# NIVAAS Diagram Design System

Version: 1.0

---

## Purpose

This document defines the visual language used by every NIVAAS diagram.

All architecture, ER, ML, RAG, ELT and deployment diagrams must follow these standards.

---

# Typography

Font: Inter

Header Size: 14

Body Size: 11

Header Color: White

Body Color: #374151

---

# Entity Style

Shape: Rounded Rectangle

Corner Radius: 10px

Border Width: 2px

Shadow: Small

Width: 220px

Height: Auto

Padding: 8px

# Layout

Business entities appear at the top.

Historical entities below the business layer.

Infrastructure below the historical layer.

Machine Learning, AI and Computer Vision remain grouped by capability.

All diagrams should read from top to bottom.
